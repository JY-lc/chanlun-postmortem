# 实验报告：把缠论结构当作"当下可得"特征（strict_open 路线）
**2026-09-10 · 借鉴定性处理的最后一个实验 · 走完整验收**

---

## 一、实验设计（严格无未来函数）

| 项目 | 设计 |
|---|---|
| 思路 | 借鉴 chan.py 的 `strict_open` / cbsp 思想：**只用"截至当日"的K线**提取缠论结构特征，不依赖事后才知道的"最终结构" |
| 特征提取 | 对每个交易月末 t，用 `klines[:t]` **重新跑一次 analyze** → 提取"当下"的最后一笔/中枢/背驰等（约 7400 次增量分析） |
| 标签 | 次月首日开盘买入 → 下月末收盘（执行修正，无前视） |
| 样本 | 中证1000 前80只，2016-07~2026-07，**7308 条月频样本** |
| 特征（10个） | 笔方向、当前笔已走天数、当前笔涨幅、中枢位置、是否在中枢内、是否在中枢上方、**背驰度**(当前笔/前一笔MACD面积比)、均线多头、均线空头、距最后分型天数 |
| 验收 | IC + t值 + 分层单调性 + 组合（含成本）+ 样本外分段 |

---

## 二、单特征检验：缠论核心概念无预测力

| 特征 | IC | t值 | 分层Q1→Q5（未来月收益%） | 单调性 |
|---|---|---|---|---|
| **bi_bars**（当前笔天数） | +0.040 | **+2.76** | 0.43→1.30 | 非单调 |
| **bi_ret**（当前笔涨幅） | −0.041 | −2.08 | 1.35→1.12 | 非单调 |
| ma_bear（均线空头） | +0.033 | +1.57 | 0.87→0.87 | 非单调 |
| **div_ratio（背驰度）** | +0.021 | +1.51 | 0.56→1.28 | 非单调 |
| zs_pos（中枢位置） | −0.024 | −1.06 | 0.79→1.07 | 非单调 |
| bi_dir（笔方向） | −0.020 | −1.19 | 1.22→0.64 | 非单调 |
| ma_bull / in_zs / above_zs / days_fx | ≈0 | <1.0 | — | 非单调 |

**关键结论**：
1. **缠论最核心的概念——背驰（div_ratio）、中枢（zs_pos/in_zs/above_zs）、笔方向——全部无显著预测力**（|t| ≤ 1.51）
2. 唯一"接近显著"的是 bi_bars(t=2.76) 和 bi_ret(t=−2.08)，但：
 - **多重检验校正后不达标**（10个特征，Bonferroni 阈值 |t|>2.81；bi_bars 2.76 刚好不够）
 - 它们本质是**已知的动量/反转效应**的代理（"笔走得久"≈趋势持续，"笔涨得多"≈短期反转），**没有提供超越简单技术指标的新信息**
3. **所有10个特征的分层都是"非单调"**——档位与未来收益没有稳定排序关系

## 三、组合检验：明显跑输"什么都不做"

用两个弱显著特征做等权打分（bi_bars高 + bi_ret低），选 Top20% 等权、月频调仓：

| 组合 | 年化 | 波动 | 夏普 | 回撤 |
|---|---|---|---|---|
| 缠论特征组合（净0.1%） | +4.22% | 29.6% | 0.07 | 59.2% |
| **基准：全池等权** | **+8.03%** | 24.8% | **0.24** | 48.4% |
| **超额** | **−3.36%** | — | −0.39 | — |

- 逐年跑赢仅 5/11 年
- **样本外不稳定**：开发期(2016-2021) 组合 −1.93% vs 基准 +6.70%（大幅跑输）；验证期(2022-2026) 组合 +12.11% vs 基准 +9.65%（略胜）

**即：花力气用缠论结构选股，结果比"什么都不做、等权持有"还差 3.36%/年，且回撤更大（59% vs 48%）。**

---

## 四、结论

1. **"缠论结构特征化"（chan.py 的 ML 路线）在本数据条件下同样无效**：
 - 核心概念（背驰）无预测力
 - 弱显著项是已知效应的代理，且未过多重检验
 - 组合层面跑输基准
2. **这验证了我们的预判**：chan.py 用 400+ 特征 + XGB/LightGBM/AutoML，但**它自己没有公布过经β对照与成本检验的实盘业绩**；特征化并不能凭空创造α——**特征若含事后信息则回测虚高，若只用当下可得信息则优势缩水**（本实验正是严格只用当下信息）
3. 至此，缠论相关的所有可能路径均已实测：
 - 买卖点直接交易（原始/确认制）❌
 - 缠论作为过滤层（小时线共振）❌
 - 缠论结构作为特征（本实验）❌

## 五、项目最终结论（完整版）

| 方向 | 检验方法 | 结论 |
|---|---|---|
| 缠论择时（原始） | 回测 | ❌ 确认滞后未来函数（20.65%→2.05%） |
| 缠论择时（确认制） | 逐日截断+β对照 | ❌ ≈池子β，夏普−0.15 |
| 缠论+小级别共振 | 小时线两档 | ❌ 皆负价值 |
| 缠论结构特征化 | IC+分层+组合+样本外 | ❌ 跑输基准3.36%/年 |
| 经典技术信号（3个原型） | 探针回测 | ❌ 无边缘 |
| 沪深300常规因子（9个） | IC检验 | ❌ 全不显著 |
| 中证1000因子 | IC+组合+中性化 | ❌ IC≠可交易；EP=小市值伪装 |
| 小盘β+风控 | 指数回测 | ❌ 指数年化−2.13%，风控只降波动 |
| **多资产风险平价** | 组合回测 | ✅ **年化6.86%/夏普0.36/回撤27.5%** |

**唯一有效产出：多资产风险平价配置**（赚跨资产分散+再平衡，不依赖任何α）。

## 六、建议

1. **停止缠论方向的所有进一步投入**（9条路径已系统性证伪，含本次特征化）
2. **落地多资产风险平价**，并补齐债券ETF（把波动从13%降到8-10%）
3. 保留：确认制引擎、验收协议（6道门槛）、每日采集、数据管道——这些是本项目的可复用资产
4. 若未来仍有研究冲动：唯一未验证的是"另类数据"（需前向积累）与"tick级微观结构"（需新数据源与设施），但门槛与成本都高
