## 一、结论：一个「年化 20.65%」策略的真实面貌

| 口径 | 年化 | 夏普 | 说明 |
|---|---|---|---|
| 原策略声称 | **20.65%** | 2.00 | 交接文档原始数字 |
| 修复数据/成本缺陷后 | 16.79% | 1.89 | 仍含未来函数 |
| **消除"确认滞后型未来函数"后** | **2.05%** | **−0.15** | **实盘可得口径** |
| 同期等权持有同池标的（β） | 2.01% | — | 策略 ≈ β，**无超额** |
| 同期沪深300 | −0.85% | — | — |

**收益拆解**：
```
声称 20.65%
  − 14.7pp  确认滞后型未来函数（虚假收益）
  −  1.0pp  未计交易成本（滑点/印花税）
  = 2.05%   真实表现 ≈ 无风险利率 ≈ 池子 β（2.01%）
```

## 二、⭐ 最重要的发现：确认滞后导致的「虚假收益」

### 2.1 机制

缠论的分型**需要右侧 K 线确认**，且笔端点在出现反向分型前会**持续被替换**。因此：

- 「全历史一次性计算」得到的信号，其标注日期 = **笔终点日**
- 但在该日期，实盘中**这个信号还不可见**（笔还没被确认）
- 回测按该日期撮合 → **用了当时不可能获得的信息** → 系统性虚高

这**不是普通的数据错误**，而是**结构性的未来函数**——它恰好落在"反转后涨幅最陡"的那一段，因此对收益的贡献极大。

### 2.2 量化证据（均为真实复跑）

| 检验项 | 结果 |
|---|---|
| 买点确认滞后 | 中位 **1 个交易日**（57% 为 +1 日），最长 19 日 |
| **幻影信号占比** | **24.8%** 的买点在全历史分析中存在，但逐日截断扫描下**根本不会出现** |
| 严格口径（笔完全定型） | 滞后中位 **7 个交易日**、价格偏离中位 **+3.47%** |
| 交叉验证 | 18 个抽样信号中，14 个的"逐日截断首见日"与推导完全一致，2 个**永不出现** |

| 三种可获得口径 | 年化 | 夏普 | 回撤 | 买入笔数 |
|---|---|---|---|---|
| A 严格等确认（等笔定型、剔除幻影） | +2.05% | −0.15 | 5.55% | 103 |
| B 分型确认即买（含幻影，**不可实现**） | +6.83% | +0.64 | 6.21% | 127 |
| C 先开后验（chan.py 方案） | +2.72% | −0.07 | 2.64% | 189 |

> **关键点**：最好看的 B 口径（6.83%）恰恰是不可实现的——它依赖那 24.8% 的幻影信号。**消除未来函数后，策略收益从 16.79% 塌缩到 2.05%。**

### 2.3 修复方式（已实现为引擎默认）

**逐日确认制**：对每个交易日 t，仅用截至 t 的 K 线重新计算信号，其**首次出现的日期**才是实盘可得日；同时剔除幻影信号。见 `chanlun/backtest.py` 的 `resolve_confirmation_dates()` 与 `config.USE_CONFIRMATION_DELAY`。

## 三、11 条改进路径：全部实测无效

| # | 路径 | 结论 |
|---|---|---|
| 1 | 原策略（含未来函数） | 20.65%，不可信 |
| 2 | 逐日确认制 | 2.05% ≈ β |
| 3 | 小级别 / 小时线共振 | 负价值（严格档砍掉96.7%盈利） |
| 4 | 经典技术信号（趋势突破/超跌企稳/回踩）×3 | 0.38% / −0.46% / 0.69%，无边缘 |
| 5 | 沪深300 横截面因子 ×9 | \|t\| 全部 <1.6，不显著 |
| 6 | 中证1000 横截面因子 | LIQ/REV1 组合层跑输基准；EP 系"小市值伪装" |
| 7 | 缠论结构特征化（当下可得特征） | 跑输基准 **3.36%/年** |
| 8 | MACD 辅助确认（10 变体） | 全部无改善，夏普仍为负 |
| 9 | 布林辅助确认 | 无改善 |
| 10 | czsc 的"未完成笔长度限制" | 无效（≤7根反而略降） |
| 11 | chan.py 的"先开后验" | +2.72%，仍不可交易 |

**开源项目调研结论**：czsc / chan.py / chanlun-pro 等主流实现**都知道**确认滞后问题，但**没有解决**——它们采用"仅用已确认笔 / 限制未完成笔长度 / 盘中先开+日终后验"等工程妥协，且**均未公布经完整验收（确认制+成本+β对照+样本外）的实盘业绩**。

## 四、方法论沉淀：技术策略的 6 道验收门槛

一条命令运行：`python tools/acceptance.py`

| # | 门槛 | 检查什么 |
|---|---|---|
| 1 | **确认滞后** | 信号在其日期是否真实可得（幻影信号率） |
| 2 | **成本敏感** | 0% / 0.1% / 0.3% 滑点三档 |
| 3 | **β 对照（硬门槛）** | 必须显著超越同池等权持有 |
| 4 | **样本外** | 开发/验证分段 |
| 5 | **统计显著性** | 打乱信号日期的蒙特卡洛置换检验 |
| 6 | **多重检验** | 试验计数 + Bonferroni/BH 校正 |

### 本项目识破的四类幻觉

| 幻觉 | 检验手段 | 实例 |
|---|---|---|
| **未来函数**（信号当时不可得） | 确认制 + 逐日截断 | 16.79% → **2.05%** |
| **把 β 当 α** | β 对照（等权持有基准） | 超额仅 +0.04pp |
| **IC 显著 ≠ 可交易** | IC → 分层 → 组合 → 中性化 | LIQ 的 t=−4.99 却跑输基准 |
| **幸存者偏差** | 用指数/历史成分，勿用当前成分回溯 | 同期：指数 −2.13% vs 当前成分回溯 +5.06%（**偏差 7pp/年**） |
