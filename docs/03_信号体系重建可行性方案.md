# 信号体系重建 可行性方案
**2026-09-10 · 缠论策略项目 · 基于确认制实装后的全部实测证据**

---

## 一、为什么必须重建（证据链）

| 证据 | 数字 | 含义 |
|---|---|---|
| 消除未来函数后 | 年化 2.05%、夏普 −0.15 | 策略自身失效 |
| **β对照：全池58只等权持有** | **年化 +2.01%**（中位1.47%，72%标的正收益） | **策略收益 ≈ 池子β，择时未创造α（仅+0.04pp）** |
| 经典"当日可算"信号探针 | P1趋势突破 0.38%/回撤44.8%；P2超跌企稳 −0.46%/22.1%；P3多头回踩 0.69%/18.7% | 随手设计的日线择时信号**也都没有边缘** |
| 蒙特卡洛（确认制） | 仅回撤维度 p=0.033 显著；年化/夏普 p=0.067 边缘 | 有价值的是"纪律/风控"，不是选时 |
| 交易结构 | 59% 退出为时间止损 | 信号捕捉不到趋势 |

**结论：问题不是"缠论信号选得不好"，而是「日线级、单标的、时间序列择时」在这个池子/这段历史里无法产生超额收益。** 换一套择时信号（无论缠论还是均线突破）都不会改变这一点。

> 探针的局限（须诚实说明）：三个原型未做参数优化、卖出规则简单，不能证明这些方向"必然无效"；但它证明「凭直觉设计信号」不解决问题——重建必须靠严格流程筛选，而非灵感。

## 二、重建第一原则：验收协议先行

原策略之所以跑了10轮才暴露问题，根源是**没有把"信号可得性"和"基准对照"写进验收**。新体系必须固化以下门槛（工具已就绪）：

| 门槛 | 要求 | 工具 |
|---|---|---|
| ① 确认滞后 | 信号在决策时点 100% 可得；幻影信号率必须为 0 | 确认制引擎（已实装，默认开启） |
| ② 交易成本 | 滑点 0.1% 基准 + 0%/0.3% 敏感档；T+1_open 执行 | config 开关 |
| ③ **β对照（新增硬门槛）** | **必须显著超越"同池等权持有"**（原策略恰好等于β，这是最有效的杀手指标） | `probe_beta.py` |
| ④ 样本外 | 2016-2022 开发 → 2023-2026 一次性验证（不许回头调参） | Walk-Forward |
| ⑤ 统计显著性 | 打乱信号蒙特卡洛 p<0.05（收益+夏普维度） | `mc_confirm.py` |
| ⑥ 多重检验纪律 | 记录全部试验次数；同一想法参数尝试 ≤3 次；报告时做 BH 校正 | 试验日志（需新建） |

**核心变化**：今后的验收不再看"年化多少"，而看 **"是否在确认制口径下、显著超越同池等权持有"**。

## 三、方向筛选（按证据与数据可得性排序）

### 方向 A（推荐优先）：从「择时」转向「横截面选股」
- **理由**：池内分化远大于时序β——72%标的10年正收益、头部（纳指ETF/紫金/海螺等）远超中位，α 存在于"选谁"而非"何时买"
- **可复用数据**：同花顺财务（利润表/现金流）、板块成分、指数成分
- **⚠️ 数据约束（已实测）**：同花顺估值端点**只提供最新快照、不提供历史** → 历史PE/PB需自行用「财报+价格」重构（可行但有工作量）
- **方法**：月度调仓、多因子打分（价值/质量/动量），先做 **IC/IR 检验**（不需要交易，纯统计），再进组合回测
- **验收**：分层单调性 + 多空组合 + 超越等权基准

### 方向 B：事件驱动（同花顺特色数据）
- 涨停/炸板/连板/异动/龙虎榜 → 统计事件后 1/3/5/10/20 日收益
- **⚠️ 前置探测**：这些端点是否提供**历史**数据（能力边界标注为"today-only 能力"需先确认）——若只能实时，则仅能做模拟盘信号积累，**无法回测**（优先级取决于探测结果）

### 方向 C：降低问题难度（宽基ETF + 大周期 + 低频）
- 单标的宽基ETF（510300/510500）、周线/月频、持仓数月
- 好处：无个股黑天鹅/无ST、流动性好；大周期下"确认滞后"的相对代价更小
- 局限：ETF择时本质仍是β择时，天花板可能不高——**先做"是否跑赢持有"的最小验证再投入**

### 方向 D（兜底）：接受"该池无α"
- 若 A/B/C 均未通过验收 → 明确结论：当前池+周期无可用α
- 转化路径：扩池到全市场（同花顺全市场数据已可用）或转向资产配置（股债/跨境/商品ETF轮动，用现有ETF池）

### 已排除的方向
- ❌ 继续调缠论参数（笔长/背驰阈值/时间止损）——根因是结构性确认滞后，非参数
- ❌ 换用其他"事后结构"类指标（中枢/线段/浪型）——同类确认滞后
- ❌ 增加日内/小时线共振——已实测负价值（材料3.5，两档皆负）

## 四、分阶段实施计划

| 阶段 | 内容 | 产出 | 门槛/工时 |
|---|---|---|---|
| **P0 ✅已完成** | 确认制引擎 + 审计工具 + β基准 | 可信回测口径 | — |
| **P1 (3-5天)** | ①探测同花顺特色数据/估值的**历史可得性**；②固化验收协议为脚本（一条命令出全部门槛）；③建立试验日志（防p-hacking） | `tools/acceptance.py`、试验日志 | 无门槛 |
| **P2 (1-2周)** | 方向A：因子 IC/IR 筛选（不交易） | 因子有效性报告（IC>0.03、IR>0.3 才进下一阶段） | 纯统计，成本低 |
| **P3 (1-2周)** | 通过IC的少数因子 → 组合回测，走完整验收协议 | 是否超越等权基准 | **必须过6道门槛** |
| **P4 (2周+3个月)** | 单策略模拟盘（确认制口径，实测滑点） | 上线决策依据 | 模拟盘达标线沿用 |
| **失败预案** | P2/P3 过不了 → 进入方向B或C；全不过 → 方向D（扩池/资产配置） | 每阶段独立止损 | 不加码沉没成本 |

## 五、风险与纪律

1. **数据挖掘风险**（最大）——横截面因子最容易过拟合：强制样本外 + 试验计数 + BH校正；发现"漂亮结果"先怀疑而非兴奋
2. **数据质量**：继续用双源校验（`tools/verify_data_sources.py`）；新浪源已知问题（000001类代码冲突、未复权）已修复/评估
3. **成本敏感**：所有结果同时报 0%/0.1%/0.3% 滑点三档（原策略对滑点极敏感：0.1%吃掉1pp年化）
4. **执行现实**：日线+次日开盘挂单；避免需要盘中盯盘的方案（尾盘抢单已被证明次优）
5. **诚实的终止条件**：预先写下"如果 XX 就停止"，避免无限投入

> 本方案为技术可行性评估，不构成投资建议。核心判断基于实测：该策略/该池/该周期，日线择时无法产生超越β的超额收益。
