## 二、机制核实（代码级证据）

材料描述的机制链条，逐条在代码中核实**全部成立**：

1. **分型需要右侧K线**（`chanlun/core.py::_find_fractals`）
   ```python
   for i in range(1, len(merged) - 1):        # 需要 next_k = merged[i+1] 存在
       if curr_k.high > prev_k.high and curr_k.high > next_k.high ...
           fractals.append(Fractal(date=curr_k.date, ...))   # ← 日期记在“中间K线”
   ```
   → 分型**日期**记在中间K线日，但**成立**需要右侧K线出现 → 当日不可得。

2. **笔端点在持续被替换**（`_build_strokes`）
   ```python
   if curr.type == last.type:            # 同类分型：取更极端的
       if curr.type == 'top':
           if curr.high > last.high: selected[-1] = curr    # ← “最后一个分型”不稳定
       continue
   ...
   if ok: selected.append(curr)          # ← 出现反向分型才把上一个分型“定型”
   ```
   → 数据末端（最新）笔端点在**出现反向分型前一直是候选态**；只有被反向分型确认后才定型。
   → 这解释了材料观察到的「中位滞后1日、最长12日」以及「部分信号永远不出现」。

3. **回测按 signal.date（笔终点日）撮合**（`chanlun/backtest.py::run`）
   → 全历史一次 analyze+detect 得到全部信号，按 `signal.date` 撮合次日开盘。
   → 与材料定性一致：**信号在“尚不可得之日”被执行**。

**材料未覆盖的机制细节**（本审查补充）：
- 同类分型替换 → 不仅“迟到”，还会**改变笔的归属**（同一低点在滚动视图下可能根本不成笔）
- 因此“确认滞后”不是固定延时，而是「**可见性不确定**」：部分信号在截断视图下永久不出现（下节量化）

## 三、三口径实测（58只全池，2016-01~2026-08，T+1_open）

| 口径 | 定义 | 年化 | 回撤 | 夏普 | 胜率 | 盈亏比 | 买入 |
|---|---|---|---|---|---|---|---|
| **A 原口径** | 按 signal.date 撮合（含未来函数） | 16.79% | 4.53% | 1.89 | 88.8% | 7.75 | 126 |
| **B 分型确认日** | 右侧K线出现即行动（不验证截断可见性） | 6.83% | 6.21% | 0.64 | 61.9% | 2.24 | 127 |
| **C 笔定型日** | 出现反向分型、笔成立才行动（最严） | 2.11% | 9.83% | −0.10 | 54.0% | 1.37 | 128 |
| **D 逐日确认制** | 收盘后逐日截断扫描，取真实首见日（=实盘流程） | **2.05%** | 5.55% | **−0.15** | 55.9% | 1.52 | 103 |

**关键量化（D口径构建过程）**：
- 买点信号 294 个 → 截断扫描可确认 **221** 个，**幻影剔除 73 个（24.8%）**
- 买点确认滞后：**中位 1 个交易日**（57% 为 +1 日），均值 2.55 日，最大 19 日
- 价格偏离（确认日+1开盘 vs 原日+1开盘）：中位 **+3.47%**、均值 +4.23%、最大 +43.3%、86% 为正

**结论**：未来函数贡献了 16.79% 中的约 **14.7pp**。其中 **~25% 的买点在实盘截断扫描下根本不存在**（幻影信号）——这批“事后最优、当时不可见”的信号正是未来函数的主要载体。

## 四、交叉验证（证明结论可靠）

对 18 个信号做「逐日截断重跑 vs 推导」对照：
- **14/18 完全一致**（截断首见日 = 推导的分型确认日）
- 2/18 截断首见比推导早 1~4 天（合并K线结构差异，量级很小）
- 2/18 在 40 天窗口内**永不出现**（幻影信号，与 24.8% 的比例一致）

**两个独立口径互相印证**：D（逐日截断，2.05%）与 C（笔定型推导，2.11%）几乎相同 → 结论稳健，非实现偏差。

## 五、对材料四点审查问题的答复

### Q1 确认日定义 & 低成本近似
**结论：不需要复杂定义——「实盘第一个能看见该信号的日子」就是确认日，逐日截断扫描就是规范实现。**

- 实测表明：截断首见日 ≈ 分型确认日（T0+1，57%）——**比材料设想的“笔完全成立”更宽松也更贴实盘**
- 理论更严格的定义（新笔成立/特征序列分型）会把确认再推迟约 7 个交易日（C口径），但对最终结果影响很小（2.11% vs 2.05%）
- **低成本等价实现**（本审查已验证，零额外分析成本）：
  1. 全历史 analyze 一次，复刻 `_build_strokes` 选择过程 → 得到每个笔端点分型的“定型日”映射
  2. 对买点信号用"逐日截断"在 ≤20 天窗口内验证首见日（每个信号平均仅需 1~3 次局部 analyze）
  3. 窗口内检不出 → 判为幻影信号，**剔除**
  - 全池 58 只完成耗时 **26 秒**（对比：真正逐日全量重跑约 7 小时/只）
- 建议将「逐日确认制」做成回测引擎的一个模式（`execution_mode='T_confirm'` 或独立审计开关），供后续策略默认使用

### Q2 残余价值评估与去留
**客观数据已经给出答案：**

| 口径 | 年化 | 夏普 | 计入 0.1% 滑点后 |
|---|---|---|---|
| D 逐日确认制 | 2.05% | −0.15 | **负收益**（滑点成本 ≈ 1pp/年，见实盘回测报告） |
| C 笔定型 | 2.11% | −0.10 | 负收益 |

- 对比基准：无风险利率约 2%、沪深300同期年化约 3~4%
- **策略的“超额收益”在消除未来函数后完全消失，且回撤（5.5%~9.8%）高于无风险资产**
- **建议：停止实盘化**。保留研究价值，但不具备可交易价值
- 如果坚持该方向，需要从「信号有效性」重建：先实现逐日确认制回测作为唯一可信口径，再验证任何新想法

### Q3 扫描端去预筛
- 预筛错配（0/21）**确认**，且比材料描述更严重：缠论买点日形态是「缩量背驰企稳」，与「当日冲高回落≥5%」**逻辑上互斥**
- 但需要指出：**扫描窗口(750日) 与回测窗口(全历史) 不一致**，这本身是第二个口径问题（材料3.1的“120→750日窗口”实验已侧证）
- **建议**：日线策略**不需要盘中预筛**（信号次日开盘执行）——正确流程是「收盘后全量分析」；预筛若要保留，应改为与买点形态无关的粗筛（价格/流动性/停牌/ST），绝不能用当日涨跌形态
- **优先级**：低于策略有效性重建——**先确认策略还有没有价值，再改造扫描管线**

### Q4 其他未来函数风险点（本审查补充核查）

| 风险点 | 核查结论 |
|---|---|
| 环境过滤判定时点 | ✅ 无未来函数（MA20/60/120 与60日涨跌幅均截至当日）。但**回测用 signal.date 的环境、实盘用确认日的环境** → 属确认滞后的连带项（D口径已统一为确认日环境） |
| 复权基准一致性 | ⚠️ **材料表述有误**：实际代码 `adjust="qfq"` **从未生效**，新浪接口返回**不复权原始价**（已用同花顺除权因子实测：311次除权、持仓穿越仅2笔、影响可忽略）。材料“前复权”的说法与代码不符，需澄清 |
| 日内路径假设（**新发现**） | ⚠️ `_check_stops` 在**同一日先用当日 high 更新持仓最高价、再判断当日 low 是否触发吊灯止损** → 隐含“日内最高先于最低发生”。属轻微日内路径未来函数；T+1_open 下止损次日执行，影响很小，但 T_close 模式需注意 |
| 停牌处理 | ⚠️ 引擎对缺K线日跳过（无法止损），复牌跳空风险；池内无ST股。非未来函数，但属执行风险 |
| 期末清仓价 | ⚠️ `_liquidate_all` 用全局最后交易日，个股停牌时以 `buy_price` 兜底 → 轻微失真，非未来函数 |
| 数据窗口不一致 | ⚠️ 扫描750日 vs 回测全历史 → 信号集不同（第二个独立口径问题，见Q3） |

## 六、最终建议

1. **立即停止实盘化流程**（模拟盘也应暂停并重新定义为“策略验证”而非“上线前验证”）
2. **回测引擎默认改为逐日确认制**（含幻影信号剔除），此后任何策略必须在该口径下评估
3. **不建议**在当前信号体系上继续调参——2% 年化的根因是「缠论笔/背驰信号在日线级别的确认滞后抹平了全部优势」，属结构性问题，非参数问题
4. **保留价值**：本文的方法论（确认滞后审计）可复用于任何技术指标策略；同花顺官方数据源已接入，可支撑重建研究
5. 若未来重建：优先考虑「确认即行动」的信号体系（如分型明确后的动量确认、或改用不以“笔成立”为前提的信号），并用逐日确认制做唯一验收口径
