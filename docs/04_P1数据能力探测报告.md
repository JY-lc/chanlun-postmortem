## 一、探测结论总表（全部为实测结果）

| 数据能力 | 实测历史范围 | 对重建方向的影响 |
|---|---|---|
| 个股历史K线 + 复权因子 | ✅ **全历史**（≤10年切片，`adjust=none/forward/backward`） | 已用于双源校验 |
| **财务三表**（利润表/资产负债表/现金流） | ✅ **2016年至今**（年报9期实测；季报最近20期；区间≤10年切片） | **方向A 可行** |
| **财务指标**（成长/盈利/偿债/运营/现金流） | ✅ 按报告期查询（`report=YYYY-[1-4]`），含 ROE、营收增速等 | **方向A 可行** |

| 个股异动 / 飙升榜 / 热股榜 | ❌ **仅当日快照**，无历史参数 | 只能从现在起 forward 采集 |

| 指数历史K线 | ⚠️ 仅近约8个月（实测159根） | 指数数据**继续用新浪**（2735根） |
| ETF历史K线 | ⚠️ 仅近1年 | 同上 |

## 二、对重建方向的影响判断

### 方向A：横截面选股 —— ✅ **数据可行**
- **可用**：财务三表+指标（2016+）、板块/指数成分（当前）、个股全历史K线
- **需自建**：① 历史估值指标（PB=市值/净资产、PE=市值/净利润，用财务+价格重构）② 历史成分股（避免用"今天的300只"回溯造成幸存者偏差——可近似用"上市满N年+市值前300"动态构建）
- **工作量**：中等（数据管道 3-5天 + 因子计算 2-3天）
- **建议**：这是当前数据条件下**最扎实**的方向

### 方向B：事件驱动 —— ⚠️ **部分可行**
- **涨停池有6年**（2020Q3~2026）→ 可做有限回测；但样本期仅约6年、且集中在特定市场环境（2021结构牛、2022熊、2024-2025反弹）
- **龙虎榜/热榜只有1年** → 无法回测，只能作为**实时/前向信号**
- **异动/飙升榜仅当日** → 必须**从今天开始每日采集**，积累3-6个月后才能用
- **建议**：① 立即启动每日采集任务（低成本，长期价值）② 用涨停池6年先做"涨停后N日收益"的统计探索，但结论只作参考

### 方向C：宽基ETF大周期 —— ✅ 数据可行
- ETF/指数历史K线用新浪源（已验证），不受同花顺窗口限制

### 新增可能（本次发现）
**行业/概念板块（320+390个）+ 个股全历史** → 可做「板块轮动」类信号（无需财务数据，实现快）；**财务全历史** → 可做「质量因子」（ROE/毛利/现金流），与动量组合成 F-Score 类打分

## 四、结论

1. **数据前提已扫清**：方向A（横截面，财务全历史✅）、方向C（ETF大周期✅）数据完备；方向B受窗口限制（涨停池6年可探索，其余只能前向采集）
2. **一个必须立刻做的事**：启动每日采集——异动/龙虎榜/热榜的"当日/1年"限制意味着**今天不采，明天就永久丢失**
3. **指数与ETF历史K线继续用新浪**（同花顺仅近1年/8个月）——双源校验机制保留
4. 无数据层面的"拦路虎"，重建可以按方案推进到 P2（因子IC筛选）
